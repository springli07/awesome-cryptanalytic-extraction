# 基础与原始输出 ReLU 提取：跨论文方法和复杂度比较

原 10 篇核验于 2026-09-30；2026-10-28 新核验并补入一篇，现为 Foundations 3 篇、Raw-Output ReLU Extraction 8 篇，共 11 篇，ID 与 `data/papers.json` 对齐。2026/1025 的历史归档证据保留；2026/2127 新标注撤回，原有指纹不冒充本次重新下载。没有运行论文代码，也没有复现实验。

## 统一口径 / Reading the costs

- `d₀` 为输入维度，`dᵢ` 为第 i 个隐藏层宽度，`L` 为隐藏层数，`c` 为输出维度，`N=Σᵢdᵢ` 为隐藏神经元总数，`P=Σᵢ(dᵢ₋₁+1)dᵢ` 为含偏置参数数（求和含输出层）。浅层论文的 `h` 对应 `d₁`。
- `Q` 是目标预言机调用数，`A` 是本地算术操作数，`T` 是实际时间；三者不可互换。一次返回 c 维向量的查询也不等于 c 次标量查询。`m` 是已收集临界点数，`s` 是每神经元符号试验次数，`b` 是搜索精度位数。
- **NR**：已检查相关方法/实验部分，未报告可引用的该项阶段复杂度或指标。**未核验**：没有取得需要的原文，不能据此声称作者没有报告。**推导**：本比较明确说明的推算，不是论文定理。
- “临界点数 O(N log N)”不自动等于“预言机查询 O(N log N)”：找到一个点、判断其来源、差分、精度修正均可能另耗查询；coupon-collector 还要求足够均匀的可见性。
- 所列线性代数 O(d³) 是操作计数，不是包含输入位长、条件数和数值精度的位复杂度定理。除逐篇说明外，本文检查到的这些工作没有提供统一的端到端位复杂度上界。
- ReLU 参数只能在置换及正缩放等对称性下比较。恢复签名、恢复符号、恢复部分层、得到可执行近似网络、样本标签一致、全域函数等价是不同终点。

## 一、Foundations：三种不同起点

### arxiv-1609.02943 — Stealing Machine Learning Models via Prediction APIs

**定位与假设。** 概率/置信度 API 的方程求解、决策树路径发现及标签模仿并列。不是一般深 ReLU 密码分析恢复定理。二元 logistic regression 假定能取得可逆 sigmoid 分数、独立输入及已知相应特征表达；未知预处理另外研究。

**流程与分阶段成本。**
1. 二元 LR：收集输入—分数对 → 逆 sigmoid 得线性方程 → 解权重/偏置。独立输入时 **Q=d₀+1** 必要且充分；论文未给该阶段独立 A 上界。若选标准稠密高斯消元，可推导 A=O(d₀³)，但这不是该论文复杂度声明。
2. 多类 LR / MLP：收集随机样本 → 非线性方程 → BFGS 或 SGD 优化。作者明确说不知道事先需要多少样本，试验采用 **Q=αP**，α 是实验预算因子；这不是保证精确恢复的样本上界。MLP 优化非凸，不保证全局解；其总 A/T 渐近上界 NR。
3. 决策树另用置信度伪标识符、部分输入及路径搜索；不能把 LR 的 d₀+1 套在树或神经网络上。

**实证。** Table 4 的 2,225 参数 MLP：11,125 查询，求解器 89 秒，测试/均匀样本一致率 99.96%/99.99%；不是逐权重精确等价证书。设备为双核 Intel 3.1GHz、16GB RAM、无 GPU。Table 1 的 Amazon LR 650/1,485 查询对应70/149秒，主要由约100ms/查询服务延迟决定，不能和离线求解时间混排。

**原文定位。** [2016 v2 PDF](https://arxiv.org/pdf/1609.02943v2)：§4.1.1–4.1.2，PDF pp.5–6；Table 4 p.6；Table 1 p.2；§4.2 的树攻击另行定义。代码入口：[Steal-ML](https://github.com/ftramer/Steal-ML)。

### arxiv-1909.01838 — High Accuracy and High Fidelity Extraction of Neural Networks

**定位与假设。** 将任务准确率与模型保真度明确拆开。此处比较 §6 的一隐藏层 ReLU 权重恢复，不把 §4 的大模型模仿当作同一种结果。要求 `h<d₀`、首层满行秩、64位 raw logits、可选连续输入。

**流程与分阶段成本（Appendix D 明示）。**
1. 直线扫描及两段线性检测定位临界点：Q=O(h log h)。已隔离单一折点时两线相交只需 O(1) 次查询，普通二分则随精度位数增长。
2. 临界点两侧有限差分恢复绝对比值及相对符号：每神经元 O(d₀)，整首层 **Q=O(d₀h)**。
3. 利用零空间/线性方程仅改变一个隐藏坐标，确定全局行符号：每神经元3次，**Q=O(h)**。
4. 输出层最小二乘：作者记 h 次使系统满秩；可复用已有查询，实验新增 **Q=0**。线性系统满秩及偏置处理不能省略。
5. 总查询：作者给 **O(h log h+d₀h+h)=O(d₀h)**，在其假设/计数模型下称常数因子最优。各阶段 A 的独立渐近式 NR；不能将查询最优直接写成时间最优。

**实证与限制。** Table 6 的 MNIST 模型约12.5k/25k/50k/100k参数，分别 2^17.2/2^18.2/2^19.2/2^20.2 查询，五次均值标签保真100/100/100/99.98%；首层平均约23位精度。论文同时给特殊网络的指数查询难例（Theorem 1），所以浅层成功不意味着任意网络可多项式恢复。§6.7列出深层临界点混杂、不能控制中间输入等障碍。完整阶段时间/设备匹配表 NR。

**原文定位。** [2020 v2 PDF](https://arxiv.org/pdf/1909.01838v2)：§6.1–6.7，PDF pp.7–12；Table 6 p.12；Appendix D p.18；§3.3/Theorem 1 p.4。代码可用性由单独代码审计处理。

### arxiv-1910.00744 — Reverse-Engineering Deep ReLU Networks

**定位与假设。** 几何逆向：先识别分段线性边界，利用边界弯折的先后关系恢复结构，再从交点/法向变化恢复权重。允许未知层数和宽度，但不是无条件辨识。Theorem 2 要求 Linear Regions Assumption、连接神经元的边界相交，排除测度零退化；Theorem 3 还要求能找到覆盖上一层所有有关边界的相邻区域点集。

**流程与成本。**
1. 首层：直线找折点 → 局部拟合超平面 → 分辨不弯曲的首层边界。§5.1 给**预期/启发式**查询增长 `O(d₀ N log d₁)`；每个边界点拟合需 O(d₀) 查询。其论证结合有界偏置、足够长直线、coupon collector 及自然随机假设，不应标为对任意权重的最坏情况界。
2. 深层：沿边界移动，跨越已知低层边界，比较弯折 → 恢复连接权重和上一层符号。深层查询取决于交点探索；作者称某些排列下可随参数数线性增长，未给统一端到端 Q 或 A 上界。
3. 输出及尺度/置换对齐不能免除不可见边界的可辨识性限制；定理与实际“未找到”的连接需区分。

**实证。** §6/Figs.3–4 包括随机初始化、10维随机记忆任务、MNIST784维；首层图按每个恢复参数查询数衡量；第二层实验首层宽10，四次平均，部分权重未被识别。没有可直接复用的完整深网络时间/查询总表，硬件/逐阶段 T 为 NR；不从图中目测造精确数字。

**原文定位。** [2020 v2 PDF](https://arxiv.org/pdf/1910.00744v2)：Theorems 1–2 p.5；算法§4 pp.6–9；Theorem 3及§5.1 p.10；限制§5.2 pp.10–11；§6 pp.12–13。

## 二、Raw output：同一流水线的不同瓶颈

### arxiv-2003.04884 — Cryptanalytic Extraction of Neural Network Models

**流水线。** 临界点搜索 → 差分签名 → 层归属筛选/部分签名合并 → 行符号 → 精度精炼 → 剥离前缀、迭代下一层 → 线性输出层。已知全连接 ReLU 结构、全域连续输入、完整 raw output；§4 是理想化分析，§5 才处理浮点实现。

**成本与关键边界。**
- §4.3.1 在均匀可见性假设下使用 `m ≫ N log N` 临界点，以重复签名分辨首层；这首先是点池规模，不能当完整Q。
- 一个首层临界点沿输入坐标差分得到签名，Q=O(d₀)（由§4.2的坐标差分直接推导）；深层对多个随机方向构建线性系统，只能看到当时激活坐标，需多点合并。聚类、重采样、精度精炼的统一总 Q/A 上界 NR。
- 充分收缩且可找合法前像时可多项式处理符号；“每层宽度递减”本身不充分，ReLU 非负约束也要满足。
- 一般扩张情形枚举目标层 **2^dᵢ** 个符号配置，复用已收集信息保留线性级查询而消耗指数级本地工作。具体为指数枚举乘验证代价，不应简写成 Q=2^dᵢ。
- §5.3 普通二分 b 位需约 b 查询；两条局部直线相交能直接定位孤立折点，但验证可能受多折点抵消欺骗。精度精炼不提供一般位复杂度保证。

**实证。** Table 1：784–128–1（100,480参数）Q=2^21.5，最坏输出误差上界2^-24.7；80–40–20–1（4,020参数）Q=2^18.5，最坏误差上界2^-40.4；40–20–10–10–1 为2^17.8查询。参数计数和架构不能与下一篇单纯符号实验混合。§6.2 的全域误差上界利用真参数对齐后计算，属于研究者评价，攻击者不必能仅从黑盒自行认证。

**原文定位。** [2020 v2 PDF](https://arxiv.org/pdf/2003.04884v2)：Table 1 p.4；§4.2 pp.10–12；§4.3 pp.12–16；§4.4 pp.16–19；§5 pp.20–25；§6.2 pp.26–27。代码：[google-research/cryptanalytic-model-extraction](https://github.com/google-research/cryptanalytic-model-extraction)。

### eprint-2023-1526 — Polynomial Time Cryptanalytic Extraction of Neural Network Models

**改进对象。** 继承CJM签名阶段，主要解决符号的指数搜索。原文明确承认统计/可见性启发式，不是对病态权重的无条件多项式位复杂度结论。下列数值已核对当前32页 ePrint版本，而非34页 arXiv v1排版。

**符号阶段的显式 Q/A（签名及前层已知）。**

| 方法 | 适用条件 | 单层Q | 单层算术A |
|---|---|---:|---:|
| SOE | 能取得足够独立控制方向、局部方程满秩 | dᵢ+1 | O(dᵢ³) |
| Neuron Wiggle | 可找目标临界点，有足够可控投影及统计信号 | 3s dᵢ | O(s dᵢ Dᵢ³)，Dᵢ=max(d₀,dᵢ) |
| Last Hidden Layer | 最后隐藏层、后接线性输出 | 4dL+1 | O(dL DL³) |

Wiggle 的单神经元是3s查询、O(sDᵢ³)。这些公式不能涵盖完整的前期签名提取、为收集临界点产生的全部额外查询、实际linearity checks及低置信度重试。多层符号开销须按实际使用方法逐层相加，不能将单层公式写成全网总成本。SOE 无足够秩时失效；Wiggle 有低置信度和输出抵消；最后隐藏层单独处理。

**实证。** CIFAR10 3072–256^(8)–10，1,249,802参数，测试准确率0.5249。Table 4报每神经元平均时间及可并行性；正文将256个神经元并行估算到约30分钟，不是单核全参数端到端提取时间。主要演示是在已知签名的条件下恢复符号。s=200，边缘低置信度需要重检；不能把“30分钟”直接用于包含签名恢复的模型窃取预算。

**原文定位。** [ePrint PDF](https://eprint.iacr.org/2023/1526.pdf)：§4.1 pp.15–16；§4.2 pp.16–19（Oracle Calls/Time p.19）；§4.3 pp.20–21；§5.1 p.22；§5.3/Table 1–4 pp.24–27。代码：[Crypto-TII/deti](https://github.com/Crypto-TII/deti)。

### arxiv-2406.10011 — Beyond Slow Signs in High-fidelity Model Extraction

**改进对象。** 统一CJM签名与Wiggle实现，减少重复点/多余精炼，并将符号尝试数调小；实测主瓶颈转移至签名。提出在后层提取中检验难符号组合。

**阶段与成本。**
- 继承Wiggle单层 O(s dᵢDᵢ³)算术式，实际一轮符号试验含检查用5次查询；s=15是实验选择，不是全局正确概率保证。
- 低置信度k个难神经元：继续运行 **2^k** 种符号组合的下一层签名恢复。即便并行，总工作仍指数依赖k；不能称整个增强版流水线严格多项式。
- 定向补缺签名、去重、精度精炼并行/跳过：完整新Q/A公式NR。跳过精度精炼的时间必须单独标注。

**实证与硬件。** Table 1是随机模型**第2层**而非全模型：相对统一CJM+CM，符号最多16.40×加速，总层提取最多2.52×；AMD Ryzen7 4700U、16GB。Table 2在Intel Icelake集群跑，剔除精度精炼；MNIST784–64²–1的第2层一组签名496.2s、符号6.32s、约3.05×10^6查询，换训练种子签名4649.95s。784–16^8–1第4/8层36小时后仅6/16、0/16神经元；这不是成功提取8层的证据。摘要98分钟与至少150分钟为另一整模型比较，不能替代逐层表或跨机速度排名。

**原文定位。** [2024 v1 PDF](https://arxiv.org/pdf/2406.10011v1)：§3.1–3.2 pp.4–6；§3.3–3.4 p.7；Table 1 p.8；§5.1/Table 2 pp.8–10；Appendix C p.16起。代码：[hannafoe/cryptanalytical-extraction](https://github.com/hannafoe/cryptanalytical-extraction)。

### eprint-2026-296 — Navigating the Deep: End-to-End Extraction on Deep Neural Networks

**版本。** 核对作者 [arXiv:2506.17047v2](https://arxiv.org/pdf/2506.17047v2)，2026-02-18，42页，题名为End-to-End；v1仅Signature，不能混用其摘要与新实验。

**流程。** 用子空间交恢复秩亏条件下的签名 → 筛除深层污染 → 归一化、方差过滤及精炼 → SOE与Wiggle结合处理低置信度 → 逐层端到端；输出线性层复用查询。针对控制空间、秩、数值传播及“未恢复权重”分类，不仅改符号。

**实证必须分两表。** Intel i7-14700F，搜索域为原点为中心半径10³的盒。
- Table 4是**逐层独立**攻击，前层正确性作为已知条件；不能称端到端。
- Table 5端到端：CIFAR10 3072–8^8–10，签名19h18m、Q=2^29.42；符号12m36s、Q=2^27.68。全模型有效权重恢复99.90%，但layer-coverage指标73.47%，报告(ε,δ)=(3.64×10^-4,0.26)。

### eprint-2026-1025 — Geometric Critical Point Screening（历史预印本，已撤回）

**现行状态先行。** [官方页面](https://eprint.iacr.org/2026/1025)记录2026-09-19撤回；本比较核验的是[2026-05-22官方历史PDF](https://eprint.iacr.org/archive/2026/1025/1779420008.pdf)，20页。撤回本身不证明所有论断错误，以下作为历史方法与实验声明保留，不能淡化其当前撤回状态。

**流程与假设。** 已知完整架构、连续全域输入、raw浮点输出；三条共面平行线的临界点共线/中点关系先筛选，再计算少量签名。第二层先构造首层全部激活空间，再在其中搜索三条线段。Theorem1要求 `d₀≥d₁` 且首层权重满行秩以得到全激活可行域；不是仅凭层宽大小就足够，也不是任意深层的相同结论。

**分阶段成本。**
- §3.3按候选点池S比较：传统对每点约4d₀次签名查询，Q=O(|S|d₀)，聚类时间O(|S|²)；均匀性假设下使用|S|≫N log N。
- 新方法理想情况下仅对d₁个目标点计算签名，**签名Q=O(d₁d₀)**。三点集各约N个候选，对两端点对做中点检查，作者在每对验证常数时间的假设下给**近似筛选时间O(N²)**。此式没有完整统一计入收集所有候选、查询精度/重试、最近点检索数据结构构建及维度操作成本，不能标作严格的全网位复杂度。
- §4.3第二层举例：每候选签名4d₁查询，理论只算d₂个点、实验为过滤误报算约50点；没有报告统一第二层/全网络总Q/A闭式。几何筛选后的签名上界不能冒充符号及输出层成本。

**历史实证。** Table1，MNIST784–8^8–1首层：3.5s、Q=2^16.66，对照3m24s、2^21.59；784–16^8–1首层25s、2^18.28，对照6m17s、2^21.60。**§5.2第二层实验直接使用真实首层参数**以排除前层误差，因此不是端到端。Table2，784–8^8–1第二层16s、2^14.48，对照7m5s、2^24.21；784–16^8–1为43s、2^17.02。这些是签名阶段结果，非全模型加速；§5未明确列出匹配硬件配置，硬件NR。Table1的CIFAR模型写输出1，而Table2为10，亦不可不加说明地合并。

## 三、跨论文应怎样比较

1. **查询最优只在同一预言机/假设下比较。** Jagielski浅层O(d₀h)的满秩收缩设定，不能压过深层/未知结构攻击；概率、标量logit和完整输出向量信息量不同。
2. **签名、符号与全网分栏。** CM2024消除一般符号枚举瓶颈；Foerster2024证明实际签名更慢，并为难符号保留指数分支；Navigating2026重点解决深层签名秩亏与污染。这是互补演进，不是单一总O式排行榜。
3. **成功口径分栏。** 测试集标签100%、23位参数精度、全域误差上界、有效权重99.9%、coverage73%不可互换。已知真实前层或真实符号的逐层试验必须标注。
4. **时间需同时附硬件、并行度、网络、精度和统计种子。** “30分钟/256核”符号估算、“98分钟”整模型、某层两秒，以及排除精炼的时间均不能直接相除得跨论文速度比。
5. **理论保证应注明条件和未计入成本。** 几何可见性、满秩、临界点采样分布、数值条件数、死亡/恒开神经元、置信度重试和未知宽度回溯都可能决定端到端成败。没有给出的总界应写NR，不以标题中的Polynomial补空。
