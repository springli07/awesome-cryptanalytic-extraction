## 阅读规则与公平分组

- Q 表示查询；T 表示本地计算时间；实验秒数与渐近复杂度分别陈述。一次梯度查询、一次条件续写采样、一次带 EM 轨迹的推理、一次故障推理，不是相同成本单位
- NR = 检查原文相关算法、定理及实验后，未给出该项可直接引用的独立界或统一值；NA = 该论文没有这个算法阶段。没有把未报告写成零成本
- 这些论文应分为：特殊算术/物理访问攻击；数值条件与防御评价；查询学习/辨识定理；训练式参数恢复；综述。仅在相同 oracle、恢复目标、模型、精度与硬件下比较速度
- “参数恢复”还要区分原始参数、排列/尺度等对称性下的参数、等价函数、部分层、近似分布。只测样本标签一致率不能证明全输入域等价

## A. PPML 与更强侧信道预言机（5）

### 1. eprint-2026-848 — Cryptanalytic Extraction of Neural Networks for Privacy-Preserving Machine Learning

[原文](https://eprint.iacr.org/2026/848.pdf)；2026-09-17 修订版，旧题 PPML Is More Vulnerable to Cryptanalytic Extraction Attacks

- Oracle/目标：有限环定点推理的模回绕；含原始输出与 top-1 概率变体，后者不是仅标签。恢复各层签名及符号，依赖可观察回绕与非退化映射
- 阶段：回绕点搜索（Alg.5）→局部法向/Jacobian与单点零空间→投影、多点同源聚合（§4）→伪逆最优方向与统计投票定符号（§5）→参数组合。定理3要求解析非多项式激活和局部非退化；定理5–7的符号结论依赖独立高斯系数，或宽度极限及稳定条件。没有一个涵盖全部失败重试的端到端多项式成本定理
- 可引用成本：Table5 pp24–25：首层每神经元1个回绕点；深层约9–28个，按激活/结构而变。Table7 p27：1024个隐藏神经元上，ReLU平均点数24.82→6.61，LeakyReLU 7.25→5.09，非线性14.58→5.22；100%符号正确。30%–74%是该符号基准的相对减少，不是总运行时间或整套攻击统一降幅。单个回绕点的定位查询不能直接算成1次API调用；各阶段统一墙钟T=NR
- 实验边界：§6 p24在明文中模拟MPC，M=2^64、S=2^6；逐层实验假定此前层完美恢复。3072-256×4-10与100-200×4-10各测8种激活。§6.1 p25：扩张LeakyReLU只恢复前两层；朴素多点组合O(N^m)且该方案未实测。ReLU/LeakyReLU约14-bit精度，平滑非线性约7–10-bit；sigmoid/tanh首层后不回绕而不可用。不能称为真实MPC协议端到端破解

### 2. arxiv-2503.19142 — Activation Functions Considered Harmful

[原文](https://arxiv.org/pdf/2503.19142)；v2

- Oracle/条件：SGX-Step指令粒度页访问轨迹，攻击者可辨激活实现的输入依赖分支并控制输入；比普通预测API强。第一层参数与更深层部分信息必须分列
- 阶段/成本：校准边界→逐参数二分寻找激活实现阈值→线性方程求权重/偏置（§IV–V）。§V-A p9定义Q=P·N·S，P为每神经元未知数、N为神经元数、S为二分深度；输入中心校准C=(P−1)D，D为校准所需指数增量。线性求解独立T=NR；采轨每输入约10秒（§IV-C p7），不能套用普通API延迟
- 实验：§V-A p10的保险模型首层1200参数，55步/参数达到≥3位小数，20步附近平均误差<1%。§V-B p11深层仅得到无符号收敛点集，未完整解出参数。MNIST首层100480参数的1180765次调用是全扫描外推，论文明确未报告完整恢复精度；不能写成已完成百万级恢复。没有通用端到端精确恢复定理

### 3. eprint-2024-1870 — A Divide-and-Conquer Strategy for Hard-Label Extraction of Deep Neural Networks via Side-Channel Attacks

[原文](https://eprint.iacr.org/2024/1870.pdf)；2026修订33页版

- Oracle/目标：top-1标签加逐神经元状态的EM侧信道；可分离网络内部层。§4：状态判别→二分关键点→满秩方程最小二乘签名→层内状态对齐、单层符号假设→最后分类层。已恢复前层以及可建立满秩方程是重要条件；always-on/input-off另有跨层近似处理，dead神经元可直接置零
- 成本：§4.1 p13关键点定位O(log₂(L₀/Δ))次oracle查询；§4.2 pp14–17至少须有足够独立方程，稀有状态与input-off可显著增耗，不能省略搜索成功概率。§4.3及§5.2符号对齐复用轨迹，作者报告无需额外查询；各阶段统一墙钟T=NR
- 实验：Table3 p23：MLP-a 2^17.12 Q、99.5%标签一致率；MLP-b 2^26.2 Q、97.2%；1.72M参数MLP-c 2^26 Q、93.2%；5234参数截短MobileNetv1 2^18.6 Q、88.4%。不等于全参数高精度：末层误差明显大于隐藏层
- 核心成本限定：§5.2 p21实测单EM轨迹状态判别85.9%，7/13轨迹投票分别>99%/>99.9%；后续主要提取结果采用一次轨迹即完美状态oracle的假设。实际轨迹量要乘重复采样成本，且错误可能影响成功率。不能拿上述Q与纯hard-label攻击直接宣称同威胁模型加速

### 4. arxiv-2002.11021 — SNIFF: Reverse Engineering of Neural Networks with Fault Attacks

[原文](https://arxiv.org/pdf/2002.11021)；v2

- Oracle/范围：可定位并翻转参数符号位的故障注入，加正常/故障输出；主要针对迁移学习中已知冻结特征提取器、未知最终层。不是任意未知深网黑盒提取
- 阶段：找到目标参数与适合的非零特征输入→符号故障→正常/故障输出代数求解。Theorem1 p5恢复偏置，Theorem2 p6恢复权重；权重要求对应特征非零。对Softmax输出利用比值，去掉Softmax时求解更简单
- 精确计数：Corollary1–2 p6，m个偏置需m次故障、2m次网络执行；n×m权重需nm次故障、2nm次执行。离线非零输入搜索、物理故障定位/失败重试成本没有包含在这两个计数中；这些阶段统一T=NR
- 证据性质：§V的Keras float64实验报告参数恢复误差至多约10^-13；数值实验与故障假设应分别标记。不能由代数精确公式推断任意设备可稳定实施同等故障，更不能将“每权重两次执行”移植为普通API查询上界

### 5. arxiv-1810.09076 — CSI Neural Network

[原文](https://arxiv.org/pdf/1810.09076)；USENIX版本题名有所不同

- Oracle/目标：嵌入式网络功耗/EM轨迹；恢复激活、层与神经元数、类别数、浮点权重。单轨迹输入恢复是另一个任务，不要当作单轨迹整个模型提取
- 阶段：时序/简单侧信道识别结构与激活→相关性分析猜浮点乘法中间值、逐步筛符号/指数/尾数→逐层传播已知输入。§III及§V pp5–12给出模型提取实验流程。没有通用神经网络精确恢复复杂度定理
- 成本/实验：p8权重相关分析例子每组1000条轨迹；同批轨迹可复用到多个权重。§VII p13说明随网络大小线性扩展的实现观察，并讨论额外测量约20秒；这不是统一全模型运行时间。候选浮点范围/精度影响搜索量；各阶段闭式Q/T=NR，不应拿1000轨迹当1000次普通标签查询

## B. 有限精度与防御（3）

### 6. eprint-2026-1943 — Finite-Precision Error Analysis of Cryptanalytic Model Extraction

[原文](https://eprint.iacr.org/2026/1943.pdf)；2026-09-14修订

- 性质：数值误差分析，不是一套新端到端攻击或通用防御证明。研究关键点、差分、局部签名线性求解及合并；符号/末层新算法成本=NA
- 核心定理：Theorem1 pp14–15在单次切换、前层及局部恢复矩阵准确等条件下，给出相对参数误差上界 ‖eₐ‖/‖a‖ ≤ S_Q μ_R κ₂(M̃) u_O/h。u_O是oracle误差尺度、h是差分步长、μ_R=1/|cᵣη|为下游灵敏度逆量，κ₂为非零奇异值条件数。不能删掉S_Q写成精确等式，也不能将局部界称作端到端保证
- 阶段计数：Theorem1每个方向使用4次oracle求值，m个方向对应4m个求值项（可复用与否另计）；它没有证明总关键点搜索或全攻击Q/T上界。§5.1 Proposition3 p26：相邻法向夹角θ带来κ₂=√((1+|cosθ|)/(1−|cosθ|))放大，hard-label同样有几何数值问题
- 实验：§4 pp20–24比较float32/64、步长、随机/训练网络和深度；同结构参数不同可有不同稳定性。增大h降低舍入放大却更易跨多个线性区。结论不能简化为“float32必然安全”或固定通用bit阈值；墙钟攻击阶段T=NA，数值评估统一T=NR

### 7. arxiv-2509.16546 — Train to Defend

[原文](https://arxiv.org/pdf/2509.16546)；NeurIPS 2025

- 性质/阶段：训练时神经元相似性正则化→调λ/防御层或神经元对→运行已有提取器评价。防御本身无关键点/签名/符号恢复算法，三者成本=NA；论文提供的是被测攻击耗时
- 方法条件：§3.2 Theorem1 p5以其几何/采样模型讨论分离神经元对的概率；§3.3 p7修改训练目标。该概率结论不能推出对任意自适应攻击的安全定理，也不证明相似参数对应函数不可复制
- 实验成本：Table1 p8分开列签名秒数、符号秒数、查询量。例如未防御MNIST784-16×8-1(s2)为1.12×10^4秒签名、80.37秒符号、5.65×10^6 Q；随机/训练模型统计为4个提取seed。防御模型“secure”的操作定义是48小时截断仍失败（脚注），不是已证明无限时间不可提取
- 结果边界：上述MNIST例准确率降0.92个百分点；作者报告所测配置准确率变化<1%、推理零额外开销。训练/调参独立统一T=NR。应以相同预算、效用和自适应攻击重新评价，不将48h失败写成普适密码学安全

### 9. arxiv-1807.05185 — Model Reconstruction from Model Explanations

[原文](https://arxiv.org/pdf/1807.05185)

- Oracle/模型：同时返回f(x)和输入梯度；无偏置单隐藏层ReLU，h个隐藏神经元，权重行线性独立（因此h≤d）；深网部分另为启发式实验

- 范围：精确等价函数恢复限上述浅层假设；MNIST/CIFAR10深网实验展示梯度监督可节省样本，不构成任意深网同一精确定理

### 10. arxiv-2105.09673 — An Exact Poly-Time Membership-Queries Algorithm for Extracting a Three-Layer ReLU Network

[原文](https://arxiv.org/pdf/2105.09673)；v5，ICLR 2023

- Oracle/条件：精确实值membership queries，δ-regular一般位置；深度3还须d₁≤d且顶层各相关偏导非零。未知宽度可恢复，但输出允许带额外仿射项的函数等价表示，并非原参数逐bit唯一恢复
- 阶段成本（§3.2）：单关键点O(log(1/δ)) Q；局部仿射d+1 Q；超平面O(d) Q；凸凹/临界判别O(1) Q。深度3：候选关键超平面→区分第一层→方向→还原顶端两层（§3.5）
- 总界（Theorem1–3 §2）：深度2，Q=O(d₁log(1/δ)+d₁d)，T=O((d₁log(1/δ)+d₁d)C_Q+d²d₁)。正正交域限制版Q=O(dd₁log(1/δ)+d₁d)，T再含d²d₁²；C_Q为一次oracle用时。深度3正式主定理给poly(d,d₁,d₂,log(1/δ))时间与查询，不能自行填成更紧指数
- 实验：本文核心为证明；统一实机端到端耗时=NR。不应由real-arithmetic多项式保证宣称有限精度、任意退化网络可快速复现

### 11. arxiv-2211.04589 — Finite Sample Identification of Wide Shallow Neural Networks with Biases

[原文](https://arxiv.org/pdf/2211.04589)

- Oracle/条件：浅层已知宽度m，输入维D，球面随机权重、受限偏置、激活满足M1–M2与可学习性M3。并非任意训练好的ReLU网络
- 阶段（Alg.1 p6）：Nh个有限差分Hessian→PCA与subspace power method找方向→高阶定向差分线性化求符号/初始偏置→固定方向的偏置梯度下降。G2 p5给n阶导张量O(D^n)函数查询；Hessian阶段因而O(Nh D²) Q，是按算法组成推得，不是独立新定理

- 实验：§5 pp10–11随机tanh网络，Tesla P100；Hessian+权重恢复最大112秒（D=50、m=1000），偏置细化最多180秒，各次总时间<5分钟。这里可报告分钟，但不能与深网/真实API/不同精度直接速度排名

### 14. arxiv-2402.04084 — Provably learning a multi-head attention layer

- Oracle/目标：来自{±1}^{k×d}均匀分布的独立随机样本及实值层输出，不是可选实值查询或token API。m个head，非退化假设见§4；学习注意力与输出复合矩阵及分布上的小平方误差，不是恢复唯一Q/K/V因子

### 15. arxiv-2411.07536 — Model Stealing for Any Low-Rank Language Model

## 为什么不制作统一速度排行榜

1. 对手能力不等价：梯度、SGX页轨迹、EM状态、精准故障、有限环回绕与普通输出API不同。一次调用可能附带d维梯度、整个层状态或物理测量
2. 目标不等价：方向/签名、符号、全部参数、等价函数与TV近似分布不是同一完成标准；已知冻结特征提取器的末层与未知深网不是同一任务
3. 成本不等价：Big-O、采样数、二分步、wraparound points、epoch、GPU预算和墙钟秒数需独立栏位；量化误差、失败重试、oracle时延与物理采样不能抹去
4. 证据不等价：层间假定完美、噪声无误oracle模拟、参数恢复定理、48h截断失败、有限样本fidelity、综述引文均应独立标记
5. 最适合横向比较的是同组、同网络、同精度、同oracle的配对实验；例如848内部改进符号方向与Neuron Wiggle、rounding原始与自适应攻击。跨组只能比“适用边界与证据”，不能给虚假的第一名
